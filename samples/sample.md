# Nebula AI Core 知识库示例

Nebula 是一个端到端可运行的 AI 引擎，由多个单一职责的功能模块组成，包括加载器、分块器、嵌入器、向量库、检索器、重排器与大模型，并由 RAG 管线与智能体负责编排。

向量数据库是一种以向量方式存储和检索非结构化数据的数据库，擅长语义相似度搜索。它把文本、图片、音频转换成高维向量，再通过近邻检索找到语义最接近的内容。

嵌入模型负责把任意文本映射成固定维度的向量。中文文本通常采用字向量或词语的 bigram 组合来表示语义，英文则按词为单位进行编码。

混合检索同时利用稠密向量检索与稀疏 BM25 关键词检索，再用倒数排名融合（RRF）把两路结果合并，从而兼顾语义匹配与关键词精确命中。

重排器在召回结果之上做二次排序，可以进一步结合查询词与片段的词面重叠程度，提升最相关片段的排名位置。

智能体具备工具路由能力，遇到算术类问题会确定性地调用计算器工具先算出结果，遇到知识类问题则调用 RAG 工具检索知识库并生成回答。

这套架构的全部默认实现都可以在没有网络、没有模型文件、没有 API 密钥的干净环境中离线运行，因此具备良好的可复现性与可部署性。

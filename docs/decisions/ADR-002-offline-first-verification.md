# ADR-002: 离线优先的验证策略

- **状态**：Accepted（2026-09-24）
- **作者**：晨星

## Background

AI 系统常见的「文档写能跑、实际跑不起来」问题，源于验证只覆盖单元、未覆盖进程启动与跨模块链路，且依赖外部模型/网络。

## Decision

- `pytest`：逐模块独立验证，不依赖外部资源；
- `tools/scan_emoji.py`：P0 门禁，禁止 emoji 功能图标；
- `scripts/verify.py`：自包含 E2E，拉起应用跑 ingest/query/agent 成功流与关键错误流；
- 生产后端（faiss 等）在预装环境中单独冒烟，import + 真实建库检索。

## Consequences

- 正面：交付即证明「系统真的能跑」，而非仅单元通过。
- 负面：默认生成能力为抽取式，弱于真实大模型；此为可复现性换取，生产可切换。
- 关联：ADR-001（后端选型）。
